# Women Safety Web Application

## Overview

Women Safety Web Application is a web-based platform designed to improve women's safety by providing emergency SOS alerts, secure user authentication, and real-time communication features. The application enables users to quickly send alerts during emergencies and helps authorities or guardians respond promptly.

## Features

* User Registration and Login
* JWT-Based Authentication and Authorization
* Emergency SOS Alert System
* Real-Time Communication using WebSocket
* Secure Password Encryption
* RESTful APIs
* User Management
* Spring Boot Backend Architecture

## Installation

1. Clone the repository

git clone https://github.com/Piyu7371/Women-Safety-web-application.git

2. Navigate to the project directory

cd Women-Safety-web-application

3. Configure MySQL database in application.properties

4. Build the project

mvn clean install

5. Run the application

mvn spring-boot:run
